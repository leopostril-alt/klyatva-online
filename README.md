# Клятва Чотирьох — Онлайн

Та сама гра, що й настільна версія «Клятва Чотирьох», але тепер грати можна
з різних місць одночасно — гравці не мають бути в одній кімнаті. Кожен
відкриває сайт на своєму телефоні/ноутбуці, приєднується за кодом кімнати,
а спільний стан гри (Дерево Рівноваги, раунди, голосування) синхронізується
в реальному часі через сервер. Приватні дані (Каста, Приналежність,
Жетони, дії) бачить лише сам гравець — сервер розсилає їх окремо, тож
підглянути чужий екран технічно неможливо.

Обговорення вголос (публічна фаза) відбувається на вашому звичному
голосовому дзвінку — Discord, Zoom, Google Meet тощо. Сайт не замінює
дзвінок, а лише показує спільний ігровий стан, поки ви розмовляєте.

Додано вібровідгук на телефоні (Android/Chrome) на ключові моменти:
підтвердження Слова, викриття, таємну пропозицію «Заклик у Тінь»,
вигнання, перемогу/поразку. **На iPhone (Safari) вібрація не спрацює** —
це обмеження самого iOS, браузер там не дає сайтам керувати вібрацією.
На все інше це не впливає, просто без цього тактильного бонусу.

## Що змінено порівняно з "однопристрійною" версією

- Реєстрація тепер відбувається через **код кімнати** (4 літери): один
  гравець створює кімнату й отримує код, інші приєднуються за цим кодом
  зі своїх пристроїв. Кількома компаніями можна грати одночасно незалежно
  одна від одної на тому самому сайті.
- 3-хвилинний таймер після першого гравця лишився — і далі авто-старт,
  якщо зібралось 4+, або пауза й ручний старт хостом, якщо ні.
- "Хост" (той, хто створив кімнату) керує переходами між фазами, які
  раніше вирішувались на спільному ТБ (наприклад, "Перейти до таємної
  фази", "Далі" після розкриття). Таємна фаза й голосування рухаються
  далі **автоматично**, щойно всі підтвердили свій хід — не треба чекати
  на "оператора".
- Правила гри (Касти, здібності, жетони, крамниця, умови перемоги) —
  **без жодних змін** по суті.

## Локальний запуск (перевірити самому)

```
npm install
npm start
```

Відкрий `http://localhost:3000` у кількох вкладках браузера (кожна
вкладка = окремий гравець) — можна протестувати всю гру на одному
комп'ютері перед тим, як розгортати публічно.

## Як викласти сайт онлайн (безкоштовно, без власного сервера)

Найпростіший спосіб — **Render.com**: підтримує Node.js-сервіси з
WebSocket безкоштовно, без потреби у власному домені чи хостингу.

**Безкоштовний тариф Render (станом на 2026 рік):** 750 годин роботи на
місяць (цього вистачає на майже цілий місяць безперервної роботи),
512 МБ пам'яті. Сервіс "засинає" після 15 хвилин без запитів і
прокидається за ~1 хвилину після першого наступного відкриття сайту —
це нормально для епізодичних ігрових вечорів: перший, хто відкриє
посилання, трохи почекає, а поки триває гра, сервер не засне. Дані
кімнат зберігаються лише в пам'яті процесу, тому після сну/перезапуску
старі (закінчені) кімнати просто зникають — це навіть зручно, сміття
не накопичується. Не всім акаунтам Render одразу пропонує безкоштовний
сервіс без картки — якщо попросить прив'язати картку, це лише
підтвердження особи, з безкоштовного сервісу нічого не спишеться, поки
сам не перейдеш на платний план.

### Кроки розгортання на Render

1. Заведи безкоштовний акаунт на [render.com](https://render.com).
2. У Render: **New → Web Service** → підключи цей GitHub-репозиторій.
3. Налаштування:
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
4. Натисни **Create Web Service** — за пару хвилин Render видасть
   посилання типу `https://klyatva-online-XXXX.onrender.com`. Це і є
   адреса, яку відкриває кожен гравець зі свого пристрою.
5. Готово — можна грати з будь-якої точки світу.

Якщо школа/церква вже має інший хостинг з підтримкою Node.js (Railway,
Fly.io, власний VPS тощо) — сайт запускається так само командою
`npm install && npm start`, жодних додаткових налаштувань не треба.

## Структура проєкту

```
klyatva-online/
  server.js        — авторитетний ігровий рушій (усі правила, кімнати, сокети)
  package.json
  public/
    index.html      — клієнт: увесь інтерфейс і візуальний стиль гри
```
